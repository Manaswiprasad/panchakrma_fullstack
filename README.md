# panchakrma_fullstack
# Panchakarma Fullstack Project

## Overview

Panchakarma Fullstack is a modern healthcare and wellness management platform designed to streamline Panchakarma therapy services, patient management, appointment scheduling, and healthcare operations. The project follows a full-stack architecture with a responsive frontend and scalable backend.

---

## Features

### User Features

* User Registration & Login
* Secure Authentication
* Book Panchakarma Appointments
* View Therapy Details
* Track Appointment Status
* Responsive User Dashboard

### Admin Features

* Manage Patients
* Manage Therapies & Services
* Appointment Approval System
* Dashboard Analytics
* User Management

### Technical Features

* REST API Architecture
* Secure Backend Integration
* Database Connectivity
* Scalable Modular Design
* Responsive UI
* Real-Time Data Handling

## Installation & Setup

### Clone Repository

```bash
git clone https://github.com/Manaswiprasad/panchakrma_fullstack.git
```

### Navigate to Project

```bash
cd panchakrma_fullstack
```

---

## Backend Setup

```bash
cd backend
mvn spring-boot:run
```

Backend runs on:

```bash
http://localhost:8080
```

---

## Frontend Setup

```bash
cd frontend
npm install
npm start
```

Frontend runs on:

```bash
http://localhost:3000
```

## API Endpoints

| Method | Endpoint           | Description       |
| ------ | ------------------ | ----------------- |
| POST   | /api/auth/register | User Registration |
| POST   | /api/auth/login    | User Login        |
| GET    | /api/therapies     | Get Therapies     |
| POST   | /api/appointments  | Book Appointment  |
| GET    | /api/users         | Fetch Users       |
